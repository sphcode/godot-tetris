# Tetris

A small, playable Tetris clone built with Godot and GDScript. The project focuses on the core falling-block gameplay and keeps the scene and script structure easy to study.

## Requirements

- [Godot Engine](https://godotengine.org/) 4.x

## Controls

| Action | Key |
| --- | --- |
| Move left | `A` |
| Move right | `D` |
| Soft drop | `S` |
| Hard drop | `Space` |
| Rotate counter-clockwise | `Q` |
| Rotate clockwise | `E` |

## Acknowledgements

This project was started by following [CyberPotato's Godot Tetris tutorial](https://www.youtube.com/watch?v=4XxsbtvQJE0&t=3045s). Much of the initial implementation follows the tutorial, with a reorganized project structure, additional work on the later gameplay features, and several fixes made while developing the project.
